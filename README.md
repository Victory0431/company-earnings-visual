# 公司财报图解 · Company Earnings Visual

中文财报图解：每家公司一张以**利润桑基图**为主的长图 + 交互网页，覆盖利润表、现金流、资产负债表、季度趋势，支持一键导出 2160px 高清 PNG。

在线浏览：https://victory0431.github.io/company-earnings-visual/ — 需先在仓库 Settings → Pages 启用一次：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`。

---

## 1. 这个项目是怎么组织的

一句话：**壳固定不变，每家一个文件。** 主壳只负责样式、桑基引擎、导航和导出；公司的数据与图上标注都在 `companies/` 下自己的文件里。加第 50 家公司时，主壳一行都不用改。

```
index.html                 ← 壳：样式 + 桑基引擎 + 导航 + PNG 导出（一般不碰）
sync.js                    ← 扫 companies/ 目录，重写加载清单 _index.js
bundle.js                  ← 把壳和所有模块打包成一个可单独分发的 HTML
companies/
  _registry.js             ← window.CO = [] 与 addCompany()，最先加载
  _index.js                ← 由 sync.js 生成：window.ORDER = ["ali","wc",...]
  _order.txt               ← 导航顺序，一行一个 id（sync.js 按它排序）
  _template.js             ← 新增公司的模板，复制它开始
  ali.js  wc.js  msft.js   ← 各自的 数据 + draw()
ROADMAP.md                 ← 待加入队列与进度
```

加载顺序由 `index.html` 里三个 script 决定，**不能调换**：

```html
<script src="companies/_registry.js"></script>   <!-- 先有注册表 -->
<script src="companies/_index.js"></script>      <!-- 再读清单 ORDER -->
<script>ORDER.forEach(...document.write('<script src="companies/'+id+'.js">'))</script>
<!-- 最后才是主脚本 -->
```

`window.CO` 由各模块 `addCompany()` 往里塞；主脚本读到 `CO` 才建导航。**loader 必须写在主脚本之前**，否则页面白屏。

## 2. 新增一家公司：三步

### 第 1 步：复制模板

```
复制 companies/_template.js → companies/<id>.js
```

`<id>` 是短英文小写，只用字母数字：`amzn`、`googl`、`orcl`、`nvda`、`amd`、`tsmc`、`asml`、`meta`、`tencent`。

改开头四行：

| 字段 | 含义 | 例 |
|---|---|---|
| `id` | 模块 id，必须与文件名一致 | `"amzn"` |
| `nav` | 导航按钮上的短名 | `"亚马逊"` |
| `name` | 公司法定全称 | `"Amazon.com, Inc."` |
| `code` | 交易所与代码 | `"NASDAQ: AMZN"` |
| `period` | 财报期间（必须写清财年季度） | `"2026年第三季度（7—9月）"` |
| `end` | 期末日 | `"2026年9月30日"` |
| `disclosed` | 实际发布日期 | `"2026-10-29"` |
| `basis` | 会计准则 + 是否审计 + 单季/累计 | `"US GAAP · 未经审计 · 单季口径"` |
| `unit` | 金额单位，**全篇统一** | `"亿美元"` |
| `title` | 主图大标题 | `"亚马逊怎么赚钱"` |
| `sub` | 副标题，写清同比基准 | `"2026 Q3 利润表 · 单位：美元 · 同比对比2025 Q3"` |

### 第 2 步：填五组数据

**(a) `take` —— 首屏三句话**

固定三条，`k` 是标签，与版式约定绑定：

- `k:"经营"` — 本季经营表现（收入、利润率、驱动它的分部）
- `k:"现金"` — 现金从哪来、花到哪去
- `k:"观察"` — 下季值得盯的两个变量

每条必须带具体数字，不要写“表现良好”这种。

**(b) `poster` —— 主图**

```js
poster:{
  h:1490,        // 主图总高度（px，1080 宽坐标系）
  rev:2715.19,   // 合并营业收入，比例尺 S = (1024-56)/rev
  nodes:[...], links:[...], cards:[...]
}
```

`nodes` 每个节点的字段：

| 字段 | 说明 |
|---|---|
| `id` | 唯一，短名：`s0..s3`（顶部分部）、`rev`、`gp`、`cost`、`op`、`opex`、`ptx`、`tax`、`ni` |
| `y` | 纵向起点（手工排，同一行要对齐） |
| `h` | 节点厚度（px）。薄节点 16–22，主节点 50–64 |
| `v` | 金额，**宽度 = v × S**，所以宽度天生等比 |
| `parent` | 挂到哪个节点下；`"__X__"` 表示顶部四段铺满全宽 |
| `mode` | 缺省＝子节点自动排布；`"root"` 贯穿全宽（合并营收）；`"left"` 从左边界起按金额；`"free"` 从 `s` 起按金额（用于游离的收益项） |
| `fill` | `"ink"` 黑（结构性节点）/ `"green"` 绿（利润路径）/ `"red"` 红（流出、成本、费用） |
| `s` | 仅 `mode:"free"` 用，横向起点 |

`links` 每个流带：`{f:"起点id", t:"终点id", v:金额, k:"w"|"g"|"r"}`，`k` 决定配色（灰 / 绿 / 红）。**宽度按金额计，不做归一化。**

横向坐标完全由引擎推导：单一比例尺 + 同级统一缝隙 10px + 端口按流带金额切。所以只要 `y`、`h`、金额对，边与边、角与角天然对齐 —— **不要手写 x**。

`cards` 三张指标卡，`{l:标题, v:大字, s:脚注}`。

**(c) `cash` —— 现金流**

```js
cash:{ title:"本季现金：…", max:530,
  bars:[{l:"经营活动",v:156.90},{l:"投资活动",v:-198.31},{l:"筹资活动",v:526.95}],
  facts:[{i:"资本开支",b:"504.8亿元",s:"同比+60%"}],   // 固定四条：资本开支、FCF、最大一笔支出/来源、补充项
  note:"净利润与经营现金流差异的原因（要引用原文支持的口径）" }
```

`max` 是零轴单侧满格值，三条条形等比。

**(d) `bs` —— 资产负债，四张卡**

固定为：期末现金及现金等价物 / 更广口径（现金+短期投资，写明含哪些项）/ 有息债务（含一年内到期）/ 净现金（标注“计算值”）。与**上一个可比期末**对照。

**(e) `trend` —— 最近 5 期**

```js
trend:[{l:"FY26Q1",rev:776.73,opm:48.9,ocf:450.57,fcf:256.63}, ...]
```

缺失值写 `null`，图上会画虚线断点，**不做插补**。`trendNote` 写清哪几期是倒减得来的。

**(f) `notes` 与 `src`**

`notes` 是折叠区，每条形如 `{h:"口径：毛利−费用≠经营利润", b:"差额8亿是其他收益，已计入经营利润…"}`。至少覆盖：分部合计与抵销、毛利到经营利润的桥、非 GAAP 与 GAAP 的区别、FCF 口径、分部数据是否披露。

`src` 是来源数组，必须给原文链接（公司 IR 站点 / 交易所 / 监管备案），并写清表名与报告期。

### 第 3 步：改顺序 + 重新生成清单

```
node sync.js
```

它会扫 `companies/*.js`（跳过 `_` 开头），按 `_order.txt` 排序，重写 `_index.js`。

如果只是临时加一家、不想跑脚本，也可以手工两步：

1. `companies/_order.txt` 追加一行 `<id>`
2. `companies/_index.js` 里 `window.ORDER=["ali","wc","msft","<id>"]`

两个地方必须一致，否则那家的模块不会加载，页面顶部会出现红字提示“有 N 个公司模块没加载成功”。

## 3. `draw()`：主图上的文字标注

数据（节点位置）由引擎算，**文字和图标由每家自己画**。签名固定：

```js
draw:function(t,q,rect,icon,push,co,X,F,fmt,fmt0){ ... }
```

| 注入 | 用法 |
|---|---|
| `t(x,y,文本,{size,weight,fill,anchor,ls,opa})` | 画文字，默认居中 |
| `q(id)` | 取节点坐标 `{s,e,w,c,y,h}`：`s`左、`e`右、`w`宽、`c`中心、`y`顶、`h`厚 |
| `rect(x,y,w,h,fill,rx)` | 画方块 |
| `icon(name,cx,cy,size,color)` | 内置图标：`bag` `cloud` `chip` `grid` `engine` `forklift` `tractor` |
| `push(svgString)` | 直接塞原生 SVG（需要 `<tspan>` 富文本时用） |
| `X` | `[56,1024]`，版心左右边界 |
| `F` | 颜色表：`F.ink` `F.green` `F.greenT` `F.red` `F.redT` `F.grey` `F.sub` `F.navy` |
| `fmt(v)` / `fmt0(v)` | 千分位一位小数 / 千分位整数 |
| `co` | 本公司的完整数据对象 |

**关键约束**：`draw` 里只能引用上面这些参数和自己的数据，**不要引用外层的 `const`** —— 模块是独立作用域，看不到主脚本内部的变量。

配色约定：绿色系＝利润路径，红色系＝流出/成本，黑色＝结构性节点（合并收入、分部横条），灰色＝辅助说明。

每个模块可以自带的 `header`：

```js
header:{tY:96, subY:142, hz:170, note:"…"}   // 标题 y、副标题 y、分隔线 y、右上角注
```

不写就用默认 `{96,142,170,""}`。

## 4. 数据纪律（硬规则）

1. **只用原文**：公司投资者关系官网、交易所公告、SEC/HKEX 备案。不用二手转述。
2. **加总必须闭合**：绘图前用原始精度核对分部合计、利润桥、现金余额变动；显示时再四舍五入。差 0.01 是四舍五入，差 1 以上就是口径错。
3. **区分三类数**：公司披露值 / 计算值（倒减、相减）/ 分析判断。后两类必须在图内和脚注标“计算值”。
4. **累计转单季**只允许在同一财年、同一口径下用相邻累计期之差，并注明。
5. **缺失就留空**：`null`，图上断点，不补、不猜。
6. **单位一次写死**：美元公司用“亿美元”，A 股港股用“亿元”，全篇不得混用（趋势图标题会自动读 `co.unit`）。
7. **利润率变化说“百分点”**，不说“%”。同比基数为零或由盈转亏时，用金额变化＋文字说明。
8. **GAAP 与 non-GAAP 分列**，不混在同一条流带上。
9. **分部间抵销单列**，不要压缩到某一分部里；分部归属不明的金额保留原披露口径。
10. 重组或会计口径变更时优先用重列数据，对不齐就注明。

## 5. 每次新增完成后必须做的验收

按顺序走，任何一步不过就不推：

1. **回算**：利润桥（毛利−费用=经营利润、经营利润+其他=税前、税前−税=净利）、分部加总 vs 合并收入、现金流三项＋汇率影响 = 期末现金变动。
2. **本地打开**：`file:///…/index.html#<id>`，确认导航多一个标签、主图无文字重叠、无串页（上一家的标注画到这一家）。
3. **导出 PNG**：点「下载高清 PNG」，宽度应为 2160，底部有完整来源脚注，中文不缺字、小字可读、无裁切。
4. **回归**：其余公司的 SVG 未变化（可用 `_构建工具/_dump2.js` 对比 `_share_<id>.svg` 的字节）。
5. **推送**：只推改动的文件，`push_files` 一次一家或一批小文件；推完核对 commit sha。

## 6. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 整页白屏 | loader 写到了主脚本之后 | 把 `_registry.js` / `_index.js` / `document.write` 三个 script 移到主脚本前 |
| 导航少一家 / 顶部红字 | `_index.js` 的 ORDER 与文件名不符 | 跑 `node sync.js`，或手工对齐两处 |
| 某家标注画到别家 | `draw()` 里 `if/else` 有 `else{` 覆盖了后续逻辑 | 把分支改成 `if(...){...}else if(...){...}`，逐段加花括号 |
| 数字或英文被拆行 | `wrap()` 断行没粘合数字串 | 用 `\u2060`（词连接符）粘住，如 `未\u2060经\u2060审\u2060计` |
| 导出图单位错 | `unit` 写了“亿元”但数据是亿美元 | 改 `unit`，趋势图标题会自动跟随 |
| `#how` 直达失效 | `show()` 回退到第一家 | 判断条件里补 `||H0==="how"` |
