新增一家公司：放进一个文件，导航自动多一个标签

总览页只负责骨架、桑基引擎和导出；每家公司的数据与标注都在 companies/ 下自己的文件里，互不干扰。

目录结构（每家公司一个 js，改一家不会碰到别家）

公司财报/
├── 财报图解总览.html      ← 壳：样式、引擎、导航、PNG 导出（一般不碰）
├── sync.js               ← 扫描目录，生成加载清单（加完文件跑一次）
└── companies/
    ├── _registry.js      ← addCompany() 注册表
    ├── _index.js         ← 由 sync.js 生成：按顺序列出要加载的文件
    ├── _order.txt        ← 导航顺序，一行一个 id
    ├── _template.js      ← 新增公司模板（复制它改名）
    ├── ali.js            ← 阿里巴巴：数据 + 主图标注
    ├── wc.js             ← 潍柴动力
    └── msft.js           ← 微软

三步

① 复制 companies/_template.js 为 companies/新id.js，改 id / nav / 公司全称 / 代码 / 报告期 / 口径 / 单位。
② 填 poster.nodes / links：只写纵向 y、h 和金额；横向坐标由引擎按“单一比例尺 + 统一缝隙 + 数据驱动端口”推导，所以边与边、角与角天然对齐。再填 take / cash / bs / trend / notes / src，其余板块自动排版。
③ 跑 node sync.js（或直接在 companies/_order.txt 添一行 id），刷新页面——导航多一个标签，点它出这家公司，「下载高清 PNG」直接可用。

主图上的文字标注写在每个文件自己的 draw() 里，注入的 t / q / rect / icon / push 与颜色表 F、fmt 都是现成的，不用重新搭版。

为什么不让页面自己“扫描文件夹”？浏览器双击打开（file://）出于安全不允许读目录和 fetch 本地文件，所以清单必须由 sync.js 预先写成 _index.js。这是唯一需要跑脚本的一步，其余全自动。

数据纪律：金额取自报表原文、加总必须闭合；推算值（单季倒减、FCF）在图内与脚注都标注“计算值”。
